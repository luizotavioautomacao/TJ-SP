## Extra: negação com quantificadores

| Q | Resposta | Por quê |
|---|---|---|
| E1 | **C** | Para desmentir "todo", basta **um** escrevente não concursado. A e D são o contrário. |
| E2 | **B** | Para desmentir "nenhum", basta **um** juiz atrasado. |
| E3 | **C** | "Algum faltou" só é mentira se **ninguém** faltou. |
| E4 | **C** | "Algum não estudou" só é mentira se **todos** estudaram. |

| E6 | **B** | "Existe" = "algum". Basta **um** advogado que seja estagiário. |
| E7 | **C** | "Nem todo" = "algum... não". A negação é "**todo**". |
| E8 | **C** | "Existe pelo menos um" = "algum". A negação é "**nenhum**". |

**Regra geral:** a negação é **o mínimo que basta para provar que a frase é mentira**.

| Frase | Negação |
|---|---|
| Se P, então Q | P **e** não Q |
| P e Q | não P **ou** não Q |
| P ou Q | não P **e** não Q |
| Todo A é B | Algum A **não** é B |
| Nenhum A é B | Algum A **é** B |
| Algum A é B | Nenhum A é B |
| Algum A não é B | Todo A é B |
